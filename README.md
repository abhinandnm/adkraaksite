# Adkraak

A modern, responsive website built for **Adkraak**, featuring interactive visuals, smooth animations, and a clean user experience.

## 🌐 Live Preview

[Visit Adkraak →](https://adkraksite.vercel.app/)

## 🛠️ Built With

* React
* Vite
* Three.js
* React Three Fiber
* Framer Motion
* Lucide React

## 🚀 Run Locally

```bash
git clone https://github.com/abhinandnm/adkraaksite.git
cd adkraaksite
npm install
npm run dev
```

## ☁️ Deployment

Deployed with **Vercel**.
